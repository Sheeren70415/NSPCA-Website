\# NSPCA Website



\## Project Description

This project is a website created for the National Council of SPCAs (NSPCA).



The website provides information about the organisation, its work, projects, news, donations and ways the public can get involved.



\## Website Pages

\- Home

\- About

\- What We Do

\- Projects

\- News

\- Get Involved

\- Donate

\- Contact



\## Technologies Used

\- HTML

\- CSS

\- JavaScript



\## Project Purpose

The purpose of this website is to provide visitors with information about the NSPCA and encourage public awareness and support for animal welfare.
